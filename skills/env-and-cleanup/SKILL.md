# 환경과 정리

## 환경 확인
- Windows에서는 실제 PowerShell 버전과 Python 실행 경로를 확인한다. Python 명령은 `python`, `py -3`, `python3` 중 실행 가능한 것을 사용한다.
- 한글·공백 경로는 안전하게 인자로 전달한다. PowerShell 파일 조작은 `-LiteralPath`를 선호한다. UTF-8 출력과 파일 인코딩을 구분하고 기존 줄바꿈을 보존한다.
- PowerShell 5.1은 `&&`를 지원하지 않는다. UTF-8 BOM 동작도 PowerShell 7과 다르다. 셸 문자열에 사용자 텍스트를 직접 이어 붙이지 않는다.
- macOS는 BSD 도구 옵션을 확인한다. 앱 설정 변경은 사용자의 요청 범위와 사용 가능한 도구에 따른다.

## 서버와 정리
- 시작한 서버의 PID·포트·로그·작업 폴더를 기록한다. “서버 열어줘” 요청에는 접속 주소를 먼저 제공한다.
- 임시 검사 프로세스는 종료한다. 사용자가 확인할 서버는 유지하고 종료 방법을 알린다. 다른 세션이 띄운 프로세스는 종료하지 않는다.
- 이번 작업에서 만든 임시 파일은 실제 경로가 작업 영역 안인지 확인한 뒤 정리한다.
- 기존 캐시·빌드 결과·이전 버전·원본의 삭제는 사용자 요청과 기존 승인을 확인한다. 새 승인이 필요하면 대상·용량·복구 가능성을 먼저 제시한다.
- 재귀 삭제·이동 전 최종 절대 경로가 의도한 대상 안인지 검사한다. PowerShell로 찾은 경로를 문자열 명령으로 만들어 다른 셸에서 지우지 않는다.
- `.codex/protected.txt`의 원본은 보존한다. 훅이 차단하면 다른 도구로 우회하지 않는다. 훅만으로 모든 삭제가 보호된다고 가정하지 않는다.
