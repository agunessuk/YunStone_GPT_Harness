# 피드백 반영

- 번호마다 요청·확정 사항·수정 대상을 나눈다. 사용자가 확정한 영역은 보존한다.
- 첨부 이미지는 직접 보고, 영상은 가능한 도구로 해당 구간을 확인한다. 볼 수 없으면 추정으로 채우지 말고 미확인이라고 적는다.
- 프로젝트 품질 기준(예: `docs/QUALITY_BAR.md`)과 비교한다. 같은 문제는 요청된 대상 안에서 함께 점검한다. 다른 프로젝트나 확정 영역까지 자동으로 넓히지 않는다.
- 크기 변경은 글자·박스·간격처럼 함께 영향을 받는 요소까지 확인한다. 게임 이펙트는 실제 시점·지속 시간·가림을 함께 본다.
- 변경 후 실제 렌더링 또는 실행 화면으로 검수한다. 실행 못 한 항목은 구분한다.
- 같은 품질 지적이 두 번 나오면 근거 날짜와 확인 방법을 품질 기준에 남긴다. 특정 프로젝트의 판단을 전역 규칙으로 일반화하지 않는다.
