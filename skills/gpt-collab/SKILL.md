# 이미지 제작과 AI 협업

역할은 제품 이름보다 사용 가능한 도구와 사용자의 지정에 따른다. 기본 구현·빌드·통합은 현재 Codex가 맡고, 이미지 제작은 사용 가능한 이미지 생성 도구를 사용한다. 시안 확정은 사용자가 한다.

## 이미지가 필요할 때
- 연결된 이미지 생성 도구와 관련 스킬이 있으면 사용한다. 없거나 사용자가 다른 AI를 지정했을 때 전달 프롬프트를 만든다.
- 용도, 크기, 개수, 투명 배경 여부, 파일 이름, 스타일, 참고 이미지, 세트 내 통일점과 구별점을 적는다.
- 외부 전달 프롬프트는 파일과 채팅 본문으로 제공한다. 현재 도구로 끝낼 수 있는 작업을 불필요하게 사용자에게 넘기지 않는다.
- 받은 이미지는 실제 크기·투명도·형식을 검사하고 최종 게임·문서·화면에 적용해 확인한다. 시안 비교가 필요하면 번호를 붙인다.
- 이미지에 편집할 글자를 고정하지 않는다. 코드 도형으로 품질 낮은 임시 그림을 만들고 완성이라고 보고하지 않는다.

## 명세·검수 결과 반영
명세(SPEC)와 완료 기준(ACCEPTANCE)을 실제 파일과 대조한다. 외부 AI의 말은 참고 자료로 취급한다. 재현되는 문제인지, 근거 위치가 있는지, 요청 범위와 확정 결정을 지키는지 확인한 뒤 채택한다. 채택하지 않은 핵심 의견은 이유를 남긴다.

다른 AI의 검수가 필요하면 관련 파일과 “수정하지 말고 반례·결함·근거를 찾아라”라는 요청을 전달한다. 사용자가 요청하지 않은 별도 에이전트나 유료 작업을 이 스킬만으로 자동 생성하지 않는다.
