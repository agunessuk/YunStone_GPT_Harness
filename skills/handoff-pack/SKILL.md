# 인계 패키지

받는 쪽은 이전 대화를 모른다고 가정한다. 원본을 유지하고 별도 폴더에 필요한 파일만 모은다.

- `START_HERE.md`: 목적, 바꾸면 안 되는 결정, 폴더 지도, 실행 명령과 기대 결과, 다음 할 일.
- `PROMPT_첫작업.md`: “너는 이전 대화를 모른다. 첨부와 이 지시를 확인한 뒤 시작해라.”로 시작하고 목표·읽는 순서·범위·완료 조건을 쓴다. 채팅 본문에도 프롬프트를 붙인다.
- `MANIFEST.json`: 파일 경로·크기·SHA-256. 매니페스트 자체의 해시는 제외한다.
- 필요한 소스·설정 예제·현재 상태·확정된 결정. 배포본이면 실행에 필요한 빌드 결과물과 리소스도 포함한다.

`.env`, 토큰, 인증정보, 개인 대화, 불필요한 로그·캐시·이전 압축본은 제외한다. 의존 패키지를 뺀다면 설치 방법과 잠금 파일을 넣는다.

새 이름으로 압축한 뒤 별도 임시 폴더에 풀어 안내한 명령을 실행한다. 직접 확인한 결과와 미확인을 구분하고 압축 파일 링크·크기를 제공한다. 현재 앱이 지원하는 첨부·파일 링크를 쓰며 존재하지 않는 모바일 접근 기능을 약속하지 않는다.
