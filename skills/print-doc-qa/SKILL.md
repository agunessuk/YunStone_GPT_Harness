# 인쇄·배포 문서 검수

문서 제작 도구나 형식별 스킬이 있으면 렌더링에 활용한다. 이 스킬은 사용자의 품질 기준을 추가한다.

1. 최종 PDF 또는 슬라이드를 렌더링해 페이지 이미지를 직접 본다. 전체 축소 시트와 의심 부분 원본 크기를 확인한다.
2. 문장·수식의 부자연스러운 줄바꿈, 문항 간격, 과도한 하단 공백, 제목의 가로·세로 위치, 글자와 박스의 균형, 잘림·넘침을 확인한다. 풀이 공간과 의도한 여백은 보존한다.
3. 요청한 단원·유형·번호·학년의 목록과 실제 개수를 대조한다. 일부 예시로 전체를 대신하지 않는다.
4. 학원명·강사명·날짜, 학생용 시험체, 불필요한 AI 안내 문구를 점검한다.
5. 수정 뒤 영향받은 다음 페이지까지 다시 렌더링한다. 렌더러가 없으면 시각 검수 미확인으로 적는다.

인쇄용 PDF와 사용자가 요청한 편집 가능한 원본을 함께 제공한다. 편집할 글자는 이미지에 고정하지 않는다. 한 시안 확정 뒤 여러 학년·차시로 확장할 때 글꼴·크기·간격 값을 유지한다.
