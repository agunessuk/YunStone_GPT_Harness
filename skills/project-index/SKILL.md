# 프로젝트 색인

색인 요청은 파일 이동·삭제 권한이 아니다. 기존 README·색인을 먼저 확인하고 필요한 부분만 보완한다.

- 최상위 `INDEX.md` 또는 README: 목적, 현재 단계, 정본 위치, 폴더별 요약·먼저 볼 파일, 실행·테스트 명령.
- 파일이 많으면 `docs/FILE_INDEX.md`: 안정된 ID, 상대 경로, 종류, 한 줄 요약, 확인 날짜. 기존 ID는 유지한다.
- 파일 목록·크기·수정 시각은 스크립트로 수집하고 의미 있는 요약만 작성한다. 빌드·캐시·복제본은 제외 목록에 명시한다.
- 큰 파일은 목차·관련 부분부터 읽는다. 읽지 않은 내용을 읽었다고 요약하지 않는다.
- 정본은 사용자 확정, 문서, 내용, Git 이력을 함께 보고 판정한다. 수정 시각만으로 최신·정본을 단정하지 않는다. 애매하면 후보로 표시한다.
- 갱신 날짜를 기록한다. 구조가 바뀌면 관련 색인을 갱신한다.
