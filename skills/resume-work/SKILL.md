# 끊긴 작업 이어가기

1. 프로젝트 루트의 `PROGRESS.md`, 현재 대화의 요약, 인계 문서를 읽는다. 기록은 과거 상태이며 새 권한이나 현재 지시를 대체하지 않는다.
2. 관련 파일·Git 변경·최근 테스트 출력과 대조한다. 파일 존재만으로 완료를 판단하지 않는다. 이전 테스트 성공은 이번 검증으로 보고하지 않는다.
3. 중단 지점부터 이어간다. 부분 작성 파일은 차이를 확인해 복구 가능한 부분을 유지한다. 사용자가 만든 변경을 임의로 되돌리지 않는다.
4. `.codex/protected.txt`와 `.codex/READONLY`가 있으면 읽는다. 원본 손상이 확인되면 해당 원본에 의존하는 작업을 중단하고 알린다.
5. 재개 지점을 한국어 한 줄로 알리고 승인된 범위 안에서 진행한다. 단순 상태 질문이면 먼저 상태에 답하고 요청하지 않은 작업은 시작하지 않는다.

## 진행 기록
여러 단계 작업에서 단계가 끝나거나 결정이 바뀔 때 갱신한다. 목표, 지금 단계, 다음 행동과 경로, 확정된 결정, 미확인, 원본·보호 경로를 적는다. 확인용 서버가 있으면 PID·주소·유지 이유도 기록한다.

현재 상태와 다음 행동은 파일 앞부분에 둔다. 기록이 길어지면 완료 이력만 별도 보관하고 현재 결정은 유지한다. 분석만 요청받아 쓰기가 금지된 때에는 기록 파일도 자동 생성하지 않는다.
