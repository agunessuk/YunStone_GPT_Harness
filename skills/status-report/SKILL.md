# 확인 가능한 상태 보고

답하기 전에 관련 산출물·실행 결과·최근 로그를 확인한다. 기억이나 이전 성공을 현재 검증으로 쓰지 않는다.

먼저 사용자가 볼 수 있는 결과로 설명한다. “렌더러를 수정”보다 “PDF 제목이 세로 가운데에 맞음”처럼 쓴다. 상태는 확인함·미확인·실패로 구분하고 확인 방법을 덧붙인다.

여러 항목은 아래 표를 쓰고, 단일 변경은 짧은 문장으로 답해도 된다.

| 항목 | 상태 | 근거 / 확인 방법 |
|---|---|---|
| 최종 PDF 생성 | 확인함 | 결과 파일 링크 |
| 실제 프린터 출력 | 미확인 | 인쇄 미리보기 또는 실물 확인 필요 |

승인이나 정보가 반드시 필요하면 무엇을 왜 어디서 해야 하는지 먼저 적는다. 다른 도구나 에이전트의 보고만 받은 것은 직접 확인과 구분한다. 긴 로그 대신 실패 원인과 다음 행동을 전달한다.
